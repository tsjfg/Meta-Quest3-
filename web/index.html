首次使用：三步搞定

需要先把运行组件下载到本地（约 60 MB，只下一次）。

1
头显开启开发者模式
手机装 Meta Horizon App → 配对头显 → 设置里打开「开发者模式」
2
下载本地组件
自动获取 adb 与 scrcpy，全部放在本工具目录下
3
USB 连线并授权
线连电脑，头显里弹出「允许 USB 调试」时点允许
正在投屏 00:00
头显未授权调试 戴上头显，在弹出的「允许 USB 调试吗」里勾选「一律允许」再点允许 —— 只需一次，之后永久记住
头显屏幕处于熄灭状态 未佩戴时近距感应会自动息屏，此时投屏画面是全黑的

设备

用 USB-C 数据线连接头显，并在头显内允许 USB 调试。

VR 应用

在电脑上直接启动头显里的 VR 应用，投屏会立刻切到该应用的实时画面。

无线连接（可选）

先用 USB 连一次，把无线调试打开后就能拔线，延迟略高于有线。
手动填写 IP 连接

投屏参数

投屏内容 = 你戴着头显时看到的画面。停在主界面且开着透视时，看到的就是真实房间；打开 VR 应用后即为 VR 画面。
