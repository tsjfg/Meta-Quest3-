================================================================
QuestCast · Meta Quest 3 投屏演示包
================================================================

【 这是什么 】

把 Meta Quest 3 的画面实时投到电脑上的本地工具。
不经过云端、不需要账号、不依赖网络，插上 USB 线就能用。

底层原理：Quest 3 是 Android 14 设备，开启开发者模式后通过
ADB 连接，用 scrcpy 直接把头显的 H.264/H.265 硬件编码流拉到
电脑解码显示。延迟低，支持录制。

如果你用的是打包好的演示包：已内置 Python 运行时 + adb + scrcpy，解压即用。

（可选）如果你是从 GitHub 克隆的仓库：
   仓库只包含源码，不内置 Python / adb / scrcpy。
   1. 安装 Python 3.9+（python.org，勾选 Add to PATH）
   2. 运行 python questcast.py，或双击 start.bat
   3. 首次启动点「下载组件」，会自动获取 adb 与 scrcpy 到 runtime\ 目录




================================================================
【 快速开始 · 三步 】
================================================================

1. 双击 start.bat
   （会弹出一个黑色命令行窗口，别关它，关掉就等于退出程序）

2. 浏览器自动打开 http://127.0.0.1:8777
   （没自动打开就手动输入这个地址）

3. 用 USB-C 数据线连接头显 → 控制台点「开始投屏」

就这三步。


================================================================
【 演示前 · 检查清单 】
================================================================

□ 头显电量 > 50%（演示时全程亮屏很耗电，建议插着电）
□ 带一根能传数据的 USB-C 线（不是只能充电的那种）
□ 头显「开发者模式」已开启
   （Meta Horizon 手机 App → 设备设置 → 开发者模式）
□ 演示电脑已安装浏览器（Edge/Chrome 都行）
□ 提前跑一遍全流程，确认能连上

★ 重要：如果换一台电脑演示，头显会重新要求授权一次。
  这是正常的，因为授权是「这台电脑 + 这台头显」配对。
  做法：戴上头显 → 会弹「允许 USB 调试吗」→ 勾选
  「一律允许使用这台计算机进行调试」→ 点允许。
  如果弹窗没出现，重启头显后再插线即可。

【 现场演示 · 建议流程 】
================================================================

第 1 步 · 建立连接（约 30 秒）
  双击 start.bat → 控制台显示「设备已连接 Quest 3」
  如果显示「未授权」，见上面那条说明。

第 2 步 · 先投主界面（约 1 分钟）
  点「开始投屏」。这时电脑上看到的是头显主界面。
  如果是透视模式，画面会是真实房间 —— 可以顺势讲一句
  「这是透视模式，能看到现实环境」，再进入下一步。

第 3 步 · 切到 VR 内容（重点）
  控制台左侧「VR 应用」下拉框 → 选一个应用 → 点「启动」
  头显里会自动打开该应用，投屏画面同步切换成 VR 内容。
  推荐用 Moss 或 Red Matter，画面漂亮、加载快。

第 4 步 · 展示调节能力
  改分辨率 / 码率 / 帧率，实时生效（需要重新点开始投屏）。
  勾「同步录制 MP4」，演示过程会录到 recordings 文件夹。

第 5 步 · 结束
  点「停止」或关掉投屏窗口，再关命令行窗口。

【 常见问题 · 现场急救 】
================================================================

■ 画面全黑
  头显没戴在头上。Quest 有近距感应，摘下来就自动熄屏，
  这时任何采集都是黑的。戴上头显（或用手遮住头显内侧的
  感应器）即可恢复。

■ 电脑上看到的是真实房间，不是 VR
  头显停在主界面，且环境设的是「透视」。打开任意 VR 应用
  就会切到 VR 画面。也可以在头显里改：
  设置 → 个性化 → 环境 → 选一个虚拟环境。

■ 画面是两个并排的圆形
  这是 Quest 原始的双目鱼眼画面。控制台「视图」选
  「单眼 · 左眼」即可，这也是默认设置。

■ 设备显示「未授权」
  控制台橙色横幅右边点「重新触发」。还不行就重启头显。
  务必勾选「一律允许」，否则每次重启电脑都要重新授权。

■ 点「开始投屏」没反应
  确认 USB 线是数据线，换一个 USB 口（直连主板，
  不要用扩展坞或前置面板）。

■ 投屏窗口自己关了
  重新点「开始投屏」即可。

■ 找不到 VR 应用列表
  点「刷新」按钮。列表最多缓存 60 秒。

【 无线投屏（备选，不插线） 】
================================================================

先用 USB 连一次，控制台点「开启无线并自动连接」，
成功后就能拔掉 USB 线，靠 Wi-Fi 投屏。
延迟比有线略高，演示建议还是用 USB。

注意：电脑和头显必须在同一个 Wi-Fi 下。

【 目录说明 】
================================================================

start.bat          双击启动（有内置 Python 就用，没有用系统的）
questcast.py       主程序（纯标准库，无第三方依赖）
web\index.html     控制台界面，可自行改样式
runtime\           adb 与 scrcpy（不入库，首次启动自动下载）
python\            内置 Python 运行时（不入库，发给别人时可自带）
recordings\        录制文件与截图都存这里（不入库）


================================================================
【 一个能力边界，演示时别踩坑 】
================================================================

本工具投出的是头显面板的原始双目缓冲，所以是鱼眼透视效果。
Meta 官方投屏那种「拉平的、正常视角的单目画面」，走的是
com.oculus.mirror 私有管线，第三方拿不到。

如果有人问「为什么不是官方投屏那种画面」，答案是：
官方走云端 + 私有管线，延迟 1~2 秒、锁 1080p、不能本地录制；
本工具走本地 ADB，延迟低、可录制、无账号，代价是原始鱼眼视角。
